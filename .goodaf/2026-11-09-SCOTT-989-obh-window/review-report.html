Elevated decisions

B1 asked for the thumbnail to load only if the engine fails, but the engine loads the thumbnail itself as its base frame, and the imagein only after it.

Options: load the thumbnail only on failure (blocks the engine); mark the fallback fetchpriority="low" as Sk3tch does (slows the engine's base frame, since it shares the download); preload both engine images in <head>, Sk3tch's other half.

Chose: two preload lines in each page's <head> (imagein as="fetch", thumbnail as="image", both crossorigin), fallback untouched. The imagein no longer waits for the thumbnail. This relaxes the plan's rule that only the three image URLs change in the vendored pages; scripts and engine bytes are untouched.

Reverse: delete the two <link rel="preload"> lines in each page and the B1 test.

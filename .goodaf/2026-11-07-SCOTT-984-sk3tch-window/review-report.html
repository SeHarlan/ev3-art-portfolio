Deviations from the spec

  • Done-when 4's "dashed bullet": the bullets look the same as before, because Sk3tch's font draws the same • (U+2022) as the removed file. Open as A1.
  • Sk3tch's keys are also off while it's minimized, not only while another window is in front: a minimized window stays last in the order and would otherwise still take keys unseen.

Elevated decisions

The plan said to drive setTheme, setKeysEnabled and stop()/start() off refs.

Options: keep five refs and a separate startup path inside the import's callback; or hold the mounted engine and shell in one state value and let the effects apply theme, keys and start once mount resolves.

Chose: one app state, because it drops five refs and the duplicated startup path while keeping the bundle's boot order (engine starts after mountPaintUi); all checks reran green.

Reverse: restore the refs, and call setKeysEnabled and start() inside the import's .then.

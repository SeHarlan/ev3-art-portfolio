Decided for you

14 decisions
  • Cancel button: none; the menu bar's Choose and About do its job, since the selector is a tab, not a modal
  • First open: no sketch mounts until the first Open, so opening the window downloads no full-size image
  • About: a direct view switch instead of the old sketch/about toggle
  • Thumbnails: 96×96 center-cropped JPEG, square like a Win95 icon cell
  • The Monitor's thumbnail: made in the browser from its 512×512 WebP source, because curl gets a Cloudflare challenge page
  • Selected-thumb dither: .p95-icon-dither, the select color masked by the shared --p95-dither
  • Selector root uses the existing .p95-field class; Open is the shared Button with Settings' dialog-button sizing
  • Skipped: moving the containing block into Window.tsx, since it would move every window's About panel
  • Skipped: unmounting the hidden sketch, since reopening the same work would then restart it
  • Selector text: p95-chrome (W95FA UI 11px), as Explorer UI text
  • Up/Down: column count read from laid-out items sharing the first row's top
  • Selector root carries classic-inset to redraw the well's bevel it covers
  • Selector mounts only while shown, so each return starts with the open work selected
  • Refresh: keeps remounting the active sketch without changing the view

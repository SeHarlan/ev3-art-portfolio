Deviations from the spec

  • remember.exe's s key saves remember-.png instead of the originals' remember-<title>.png. The one shared engine has an empty baked title, and the spec allows rewriting only script URLs, so the engine was left as published.
  • The Blob store rename went through the dashboard, not the API: the API returned 404 for the rename. The spec provides for this, and the store now reads ev3-portfolio.

Elevated decisions

Desktop icons for the 9 new windows

Options: a thumbnail, a thumbnail collage or a representational icon per entry

Chose: singles use their own preview cropped square; CEASEFIRE uses its video frame at 0.5 s, since its preview is nearly black at 56px; galleries use a 2×2 collage of their first four items

Reverse: regenerate public/images/<slug>-icon.png from another source

Storage cost guard before uploading

Options: stop and ask, or upload since the spec approved these uploads

Chose: upload. The plan's test ("past the plan's included Blob storage") has no literal answer on Pro, where Blob storage is usage-based; the 50 files add about 1.16 GB, roughly $0.03/month

Reverse: vercel blob del the 50 collection paths listed in data/zeums.ts

17 decisions
  • remember.exe window: its own file, not MediaWindow, since it alone has seeds
  • Vendored engine's baked seed: empty, so an empty seed gives the engine's random fallback
  • HTML pieces and videos stay mounted behind the selector and About; videos are paused
  • Data: one data/zeums.ts module for all 9 windows
  • A remember item's seed: the baked text, trimmed (hashing strips whitespace, so this can't change a piece)
  • Deep-link keys: CEASEFIRE, REMEMBER, SEASONS, ISAAC, PROGRESS, SINGLEPATH, TERRA, FLOWER, TUNEOUT
  • Blob paths: <slug>/<original filename>, each collection a top-level folder (your call)
  • New windows sit after Sk3tch, newest first, so the existing order doesn't move
  • s34s0ns image folder: uploaded-image/, confirmed by a range request
  • Exaltation of Isaac's video: fetched from turbo-gateway.com, since arweave.net returns 404 for it
  • About texts: condensed from each zeums description; Isaac's corrects "Primivera" to "Primavera Digitale"
  • Window sizes: 960×600 for video singles and Tune Out, 800×800 for remember.exe, A Single Path and T3RRA, 800×700 for s34s0ns, 700×700 for "Progress"
  • rememberSrc(seed) in data/zeums.ts builds the engine URL and omits ?hash= for an empty seed
  • Isaac's Blob filename gets .mp4

  • Using a seed in remember.exe clears the selected item and always reloads the engine

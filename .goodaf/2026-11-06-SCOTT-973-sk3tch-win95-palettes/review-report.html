Deviations from the spec

  • The DUET and Maurer canvases are 18px taller than before at the same window size, so they don't render exactly as before (A1).
  • In 1-Bit, unfocused windows' title-bar logos are dark on dark gray, and Maurer's focused title icon is white on white.
  • On touch screens, menu-bar and dropdown items show no selection highlight when tapped (T1).
  • The DUET and Maurer close buttons keep their PNG X (inverted in 1-Bit), since their markup lives in sketch JS, which the spec leaves as is.

Elevated decisions

Sk3tch's font sizing on the existing W95FA face would grow all rem text 1.45× and change DUET's canvas text.

Options: put size-adjust on the existing face; add a second face for the UI only.

Chose: a second face, 'W95FA UI' (Sk3tch's file), on chrome only at 11px, so window content and art keep the old face.

Reverse: point .p95-chrome at 'W95FA' and drop the new face.

Simplify deleted public/svg/corner.tsx after the grip glyph replaced its only use.

Options: keep it as dead code; delete it.

Chose: delete; git keeps it.

Reverse: git checkout main -- public/svg/corner.tsx.

Review fix F1 left title-bar icons alone in 1-Bit: inverting them would turn the focused icon white on white, since the active title bar is white.

Options: leave it; invert title-bar icons in 1-Bit only when the window is unfocused and drop Maurer's own invert when focused.

Chose: leave it, since it depends on the inactive-title color decision.

Reverse: none needed; to fix it, add a 1-Bit title-bar rule or a conditional at Window.tsx:107.

  • Window menu-bar items use Sk3tch's 6px item padding instead of a gap
  • Glyph ink from Sk3tch's icon ink vars, two inks for the grip

  • Firefox scrollbar colors only where WebKit scrollbar styling isn't supported; arrow glyphs as data-URI SVGs

  • Sketch buttons with bare-text labels shift by padding when pressed
